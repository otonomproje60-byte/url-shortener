When to Choose Each

✅ Choose This Project (Python/Flask + SQLite) if:

  • You want zero-config deployment — just docker compose up -d
  • You run on a small VPS (1 GB RAM or less)
  • You prefer Python over PHP/Node.js for maintenance
  • You need a simple API for programmatic link creation
  • You value privacy — no tracking, no external calls, your data stays yours
  • You want to understand the codebase in 10 minutes (single file, ~200 lines)
  • You don't need multi-user management or complex analytics

✅ Choose YOURLS if:

  • You need multi-user support with permissions
  • You want a mature plugin ecosystem (100+ plugins)
  • You're comfortable with PHP + MySQL
  • You need bookmarklets and browser integration
  • You want proven stability (12+ years, 12K+ stars)

✅ Choose Shlink if:

  • You need enterprise features (SAML/OIDC, API keys with roles)
  • You want detailed analytics (geo, device, referrer, time-series)
  • You need custom redirect rules (by country, device, referrer)
  • You're okay with PHP + PostgreSQL + Redis stack
  • You need batch URL creation via API

✅ Choose Kutt if:

  • You prefer Node.js/TypeScript stack
  • You need OIDC authentication (Google, GitHub, etc.)
  • You want QR code generation built-in
  • You're okay with mandatory Redis dependency
  • You like the modern UI with dashboard

Deployment Comparison

This Project (2 minutes)

# 1. Clone
git clone https://github.com/otonomproje60-byte/url-shortener
cd url-shortener

# 2. Set your public URL
echo "BASE_URL=http://your-server-ip" > .env

# 3. Deploy
docker compose up -d

# Done! Visit http://your-server-ip

YOURLS (15+ minutes)

# Requires: MySQL server, PHP-FPM, web server config
# 1. Create MySQL database and user
# 2. Download YOURLS, configure config.php (15+ settings)
# 3. Set up PHP-FPM pool
# 4. Configure nginx/Apache with rewrite rules
# 5. Run installer
# 6. Configure plugins for basic features

Shlink (10+ minutes)

# Requires: PostgreSQL, Redis
# 1. docker compose up -d postgres redis
# 2. Configure 30+ environment variables
# 3. docker compose up -d shlink
# 4. Run migrations
# 5. Create first API key via CLI

Kutt (20+ minutes)

# Requires: Redis (mandatory), PostgreSQL
# 1. docker compose up -d redis postgres
# 2. Configure 25+ environment variables
# 3. Run database migrations
# 4. Configure SMTP for email verification
# 5. Set up OAuth providers (optional)

Common Pain Points from Real Users (GitHub Issues)

YOURLS Users Report:

  • "Blank page, can't install" — PHP config issues
  • "YOURLS installed in Subdomain" — rewrite rule complexity
  • "Error updating 1.7.9 to 1.8" — upgrade breaking changes
  • "Login page accessibility issues" — 7+ accessibility issues open
  • Plugin compatibility breaks on version upgrades

Shlink Users Report:

  • "API endpoints return 404 after update" — routing issues
  • "Shortlinks work but displayed link has no domain" — config complexity
  • "PHP Segmentation Fault" — memory/extension issues
  • "Performance bottlenecks with large number of URLs" — scaling concerns
  • "Unsafe legacy renegotiation disabled" — TLS config issues

Kutt Users Report:

  • "Cannot resolve hostname of redis server" — DNS/network issues
  • "Email verification shows dangerous sign" — SMTP/TLS config
  • "OIDC authentication fails" — provider config complexity
  • "High availability setup unclear" — scaling documentation gaps
  • Redis memory pressure on larger deployments
