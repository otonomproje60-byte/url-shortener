# URL Kısaltma Servisi

Basit ve güvenilir bir URL kısaltma servisi.

## Özellikler
- Uzun URL'leri kısa linklere dönüştürme
- Orijinal URL'ye yönlendirme
- Temel istatistikler (opsiyonel)
- API entegrasyonu

## Teknolojiler
- Python/Flux veya Node.js/Express (hala değerlendirme aşaması)
- SQLite veya Redis (veri depolama)
- Docker konteynerleştirme

## Kurulum
1. Depoyu klonlayın
2. Bağımlılıkları yükleyin: `pip install -r requirements.txt` veya `npm install`
3. Veritabanını başlatın
4. Uygulamayı çalıştırın: `python app.py` veya `npm start`
